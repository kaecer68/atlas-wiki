# L/T/S 三範式對照表

> **本頁用途**:把散落在 4 個 concept/entity 頁裡的 L/T/S 定義,**橫向對齊成可一眼對照的單頁**。不引入新假說、不下新結論;只做「**已有材料的對位**」。
>
> **重要前置**:S 範式於 2026-07-15 被 kaecer 拍板重定義,**與 v0.2 / v0.4 寫的「S = 90 天時間帶」並不相容**。本頁採用重定義後的版本。**兩個版本各自保留**(見 [[concepts/atlas-three-paradigms-v0.2-summary]] 與 [[concepts/s-paradigm-redefinition]]),**標 contested 是誠實**。

---

## 1. 根本定義(一句話對照)

| 範式 | 一句話定義 | 時間尺度 | 來源 |
|------|----------|---------|------|
| **L 鐵律** | **事件必發生的時間帶**;找的是「結構已開始動、市場還沒完成解讀」的曙光 | 1 天 — 18 月 | [[concepts/atlas-three-paradigms-v0.2-summary]] |
| **T 微趨勢** | **制度 / 產業 / 資金的趨勢**;L 事件經 L2 收斂後才有資格進入 T 配置研究 | 0.5 — 3 年 | [[concepts/atlas-three-paradigms-v0.2-summary]] |
| **S 演化** | **訊號紊亂、L2 路徑未收斂的時段**(不是盤整期) | **時間不定**(30 天 ~ 1 年皆可能) | [[concepts/s-paradigm-redefinition]] |

---

## 2. 判斷標準對照(訊號狀態為準,**非時間**)

| 判斷維度 | L 範式 | T 範式 | S 範式 |
|---------|--------|--------|--------|
| **T1 美股** | 明確(漲跌 ≥ 2%) | 主流方向但有分歧 | 紊亂(漲跌 < 1% 或反覆) |
| **T2 外資** | 明確(連 3 日同向) | 主流方向有反向 | 紊亂(多空交錯) |
| **T3 其他法人** | 共識(同向) | 有主流但有反對 | 對殺中(無共識) |
| **T4 散戶** | 一致(冷或熱) | 有方向但分歧 | 分歧(冷熱混雜) |
| **L1 觸發** | 已觸發 | 已觸發(多個) | **已觸發但 L2 未收斂** |
| **L2 收斂** | 已收斂 | 部分收斂 | **未收斂** |

**判斷的核心**:**不是時間,是 L2 收斂狀態**。
來源:[[concepts/s-paradigm-redefinition]] §「S vs L vs T 的判斷標準」。

## 3. 真實工作(對使用者 — 散戶 / 草台班子)對照

| 範式 | 真實工作 | 風險動作 |
|------|---------|---------|
| **L** | 抓 L1 觸發,等待 L2 開始收斂的早期跡象 | **過早進場**(L2 未收斂) |
| **T** | L2 收斂後才評估配置;研究產業 / 制度 / 資金面 | 把 L 的短期事件當 T 趨勢買 |
| **S** | **不輸就是贏**;持續監測 L2 收斂訊號,**不進場交易** | **以為 S 結束、結果是 S 中的小反彈**,進場後又陷入新一輪 S |

**S 期間最危險的事**:**「以為 S 結束了,結果只是 S 中的小反彈」** — 進場後又陷入新的 S。
來源:[[concepts/s-paradigm-redefinition]] §「S 期間的『真實工作』是什麼?」。

## 4. 訊號工具對照(T1→T4 在三範式中的角色)

| 層 | L 範式中的角色 | T 範式中的角色 | S 範式中的角色 |
|----|------------|------------|------------|
| **T1 美股(信號燈)** | 「觸發日」的當晚表現 | 趨勢方向錨 | **訊號紊亂** |
| **T2 外資(引信)** | L2 路徑開始收斂的執行者 | 趨勢持續的燃料 | **多空交錯,無方向** |
| **T3 其他法人(真正指標)** | L2 收斂的確認者 | 趨勢的成本/籌碼結構 | **對殺中,無共識** |
| **T4 散戶(鏡像 / 韭菜)** | 反指標 — 當散戶恐慌,常是 L2 收斂末段 | 趨勢末段的確認 | **冷熱混雜,鏡像失靈** |

> T1/T2/T3/T4 在 S 範式中是**判斷「紊亂程度」**的工具,**不是「判斷方向」**的工具。
> 來源:[[concepts/t1-t4-signal-light]] 四層驅動結構。

## 5. 與三層 framework(學術 / MCP / barbaric)的對位

| 範式 | 三層 framework 對應 |
|------|------------------|
| **L** | barbaric signals 層(真實世界的政策 / 資金 / 利益是否已先動)+ MCP 層(當下資料顯示) |
| **T** | 學術層(機制是否有可移植的物理 / 制度基礎)+ MCP 層(趨勢的當下位置) |
| **S** | 三層都呈現「互相矛盾的解釋」;**沒有任何一層能單獨判斷方向** |

> 三層 framework 不是 L/T/S 的替代品;它是**判斷某個 L 事件是否正在轉成 T、或仍停在 S 紊亂期**的檢驗工具。
> 來源:[[concepts/atlas-three-paradigms-v0.2-summary]] §「與三層 framework 的對位」。

## 7. 使用順序(實戰 SOP)

```
L 觸發
   ↓
L2 路徑選擇(等收斂)
   ↓
T 趨勢確認(若 L2 已收斂)
   ↓
S 期間等待 / 防守(若 L2 未收斂)
   ↓
T1/T2/T3 收斂後才評估交易
```

**關鍵**:S 不是「**不做事**」,S 是「**等 L2 收斂**」 — 等待本身就是工作。
來源:[[concepts/atlas-three-paradigms-v0.2-summary]] §「使用順序」。

## 9. 待驗證的假說

- [ ] 三範式是否真的彼此互斥?同一個時段是否可能「**L + S 並存**」(L1 部分觸發 + L2 部分未收斂)?
- [ ] T1→T4 在 S 範式中「紊亂」是否有量化指標?目前是定性描述。
- [ ] 三個 S 範式範例(2024/8、2025/2、2026/6-7)是否真的符合 S 定義?需 kaecer 確認。
- [ ] 「S 結束」的訊號是「L2 收斂」,但 L2 收斂要連續幾日才算?需明確定義。
