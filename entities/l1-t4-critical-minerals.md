# L1-T.4 礦物資源斷供鏈

> 本頁從 L1-T multi paper 抽出，保留原始敘事與時間錨；對交易的解讀只是研究假說，不是可獲利確認。來源資料的 2025–2026 數字仍需逐項重查，故 confidence 不升 high。

## 三層 framework 讀法

- **MCP 層**：目前可用來檢查事件、資金與市場是否同步；不能把單次快照當成 50 年結構的證明。
- **學術層**：支持物理／人口／技術機制，但通常滯後，不能給出短線時點。
- **barbaric signals 層**：追蹤出口禁令、能源價格、capex、政策與人口公告；這是散戶尋找 72 小時解讀差的入口。

## 研究漏洞

- 本頁把長期結構與短期市場傳導放在同一個 paper 中，兩者時間尺度不同；後續必須用 L2／L3 資料拆開驗證。
- 「必然路徑」描述方向，不代表每個中間節點必然發生；任何跳躍都要保留 contested 可能。

# L1-T.4 — 礦物資源斷供鏈(50 年內稀土/鋰/鈷/銅)

## Step 1 現況

- **稀土加工**:中國佔全球 ~85-90%(2024 美 USGS 統計);開採 ~60%
- **鋰供應**:智利 + 澳洲 + 中國合計 ~75%(USGS 2024);加工中國 ~70%
- **鈷供應**:剛果民主共和國(DRC) ~70%,加工中國 ~75%
- **鎳供應**:印尼 + 菲律賓 ~60%;印尼 2024 起中高鎳冶煉佔全球 ~50%
- **銅供應**:智利 + 秘魯 + 剛果 + 中國合計 ~55%(USGS 2024);再生銅 ~17%(ICA)
- **石墨(陽極材料)**:中國天然石墨 60% + 合成石墨 100%(IEA 2024)

## Step 2 前提(50 年歷史軌跡)

| 年代 | 事件 | 意義 |
|------|------|------|
| 1973-1980 | 美國加州 Mountain Pass 稀土礦從最大供應商到關閉 | 環保 + 成本 + 中國崛起 → 美國稀土戰略撤退 |
| 1980s | 日本「戰略礦物清單」建立,中國低價稀土攻佔 | 全球稀土加工重心開始東移 |
| 1990s | 中國「稀土之父」徐光憲提出串級萃取理論 | 中國成本優勢 + 技術優勢雙確立 |
| 2007-2010 | 中國短暫限制稀土出口,日本遊說 WTO | 「礦物武器化」首次實驗,但 WTO 反制 |
| 2010 | 中日釣魚台撞船事件 + 中國對日稀土禁運 | 證明「礦物武器化」可短期運作 |
| 2015-2020 | MP Materials 重啟 Mountain Pass(美國) | 國家安全戰略驅動,但加工瓶頸仍在中國 |
| 2020 | 澳洲 Lynas 成為西方唯一大型稀土加工商 | 西方「去中國化」緩慢起步 |
| 2022 | 美 IRA 法案:FEOC 限制(2024 細則) | 美國本土供應鏈扶植 |
| 2023 | 歐盟 CRMA(Critical Raw Materials Act)通過 | 2030 年目標:開採 10%、加工 40%、回收 25% |
| 2024 | 加拿大 + 澳洲 + 印度 + 韓國 簽多方 MOU | 「礦物聯盟」逐步成形 |
| 2024 | 美中科技戰升級,中國 12 月禁止鎵/鍺/銻/石墨對美出口 | 第二輪「礦物武器化」實驗 |

**轉折觀察**:2024 年起,**中國不再猶豫使用「礦物武器」** — 鎵/鍺/石墨對美禁令,顯示「WTO 規則優先」已讓位於「地緣優先」。

## Step 3 觸發

| 閾值 | 觸發條件 | 影響 |
|------|---------|------|
| 任一關鍵礦物 中國加工 < 全球 70% | 預估 2030(澳/歐/美產能釋出) | 「去中國化」開始兌現 |
| 中國稀土加工佔比 > 85% 已達 20 年 | 已發生 | 系統性風險 |
| 任一大國宣布「礦物出口禁令」 | 2024 已多起(中國 + 印尼 鎳 + 沙烏地 磷) | 預期管理失敗,進入震盪 |
| 銅 / 鋰 / 鎳 年缺口 > 供需的 5% | 預估 2030-2035(IEA CRMA 預估) | 結構性短缺 |
| 全球回收比例 > 30%(任一關鍵礦) | 預估 2035-2040(鋰率先,IEA) | 開始脫離「新開採依賴」 |

## Step 4 必然路徑

```
能源轉型(同 L1-T.1)→ 礦物需求 2030 翻 1.5 倍、2040 翻 3 倍
  → 礦物勘探 capex 2024 起年增 15-20%(S&P Global)
  → 但新礦從發現到投產需 10-18 年,2025-2030 缺口存在
  → 中國加工主導 → 「礦物武器化」可能性
  → 美歐 CRMA + IRA + KPPI(韓國)+ 日本 JOGMEC → 國家資本聯盟
  → 回收路徑起步(2025 全球電池回收 ~5%,2030 目標 25%,IEA)
  → 但回收本身需要 capex + 技術,2025-2035 是「過渡期」
  → 結果:礦物價格中長期上漲壓力(銅 2030 預估 1.5x、鋰 2030 預估持平但 2035 反彈)
  → 「第二波通膨」不只是工資通膨,更是礦物通膨
```

**利害結構驗證**:
1. **誰受益?**
   - 礦業巨頭(必和必拓、嘉能可、英美資源、Freeport-McMoRan、Teck)
   - 加工新進入者(Lynas、MP Materials、Mt Cattlin 澳洲、Energy Fuels 美國)
   - 回收商(Redwood Materials、Li-Cycle、Umicore、住友金屬礦業)
   - 中國(雖然「去中國化」壓力大,但 5 年內仍主導)
2. **誰受害?**
   - 武器化對象國(美、日、韓、台、歐):依賴中國進口者
   - 下游成本承擔者(車廠、電池廠、家電):capex + 售價壓力
   - 加工瓶頸國(如歐洲):即使有礦,加工仍卡中國
3. **結構能否持續?**
   - **中國的加工壟斷:5-10 年內仍主導**,但「份額」會下降
   - **完全去中國化:50 年內仍不可能**,成本差距太大
   - **礦物武器化的成本**:中國本身也需要出口,長期是「雙刃」
4. **表象 vs 結構**:
   - **表象**:「鎵對美禁令」(2024 生效)
   - **結構**:中國 GDP 增長 ~30% 仍依賴礦物 + 製造出口;完全切斷會自傷
   - → **L1-T.4 是必然壓力,但非全面戰爭**

## Step 5 結果

| 國 | 短期 | 中期 | 長期 |
|----|------|------|------|
| 美國 | IRA + FEOC 推本土 + 盟友(澳、加)開採 | 西方加工佔比 30-40% | 完全去中國化仍不可行,但「不再依賴 70%」 |
| 中國 | 加工護城河 + 應用端(電池、光伏)領導 | 西方「去風險」加速,但中國靠低成本 + 規模 | 「有限的武器化」持續,但避免完全斷鏈 |
| 台灣 | 半導體材料高度依賴日本 + 美國 | 轉單多元化(美 + 澳 + 韓 + 印度) | 部分材料在地化(成大半導體級化學品研發中) |
| 日本 | 100% 進口 + 戰略儲備(60 日) | 加工本土化 + 回收(日本領先) | 與東南亞 / 澳洲「礦物聯盟」緊密化 |

## Step 6 數值指標

- **USGS 年度礦物摘要**
- **IEA Critical Minerals Outlook 年度報告**
- **S&P Global Metals 五年 forward curve**
- **中國海關 / 出口管制清單**(鎵、鍺、銻、石墨、稀土配額)
- **Pentagon DPA Title III 預算**(美國國防礦物投資)
- **EU CRMA 2030 目標達成追蹤**

## Step 7 其他國家

- **歐盟**:CRMA + 與加拿大 / 烏克蘭 / 哈薩克 / 阿根廷 MOU
- **DRC**:鈷的政治穩定(與盧旺達 + 烏干達衝突)影響全球供應鏈
- **印尼**:鎳 + 鋁土礦出口禁令 + EV 電池本土化(2027 目標)
- **澳洲**:鋰 + 稀土「去中國化」最大受益者(2024 預估成為全球第二大礦物出口國)
- **智利 / 阿根廷 / 玻利維亞**:「鋰三角」+ 玻國國有化議題
- **俄羅斯**:鈀 + 鈦 + 鎳,西方制裁強化其向中印傾斜

## Step 8 對台股傳導(這條對台灣最重要!)

**直接影響**:
- **半導體材料(無敵重要)**:日本 + 美國為主 + 中國(部分)
  - 矽晶圓(信越、SUMCO、環球晶 6488):電子級矽
  - 光罩(Photronics、Toppan、DNP):半導體光罩
  - 蝕刻氣體(三井、住友、關東電化):中國受限
  - CMP 漿料(Cabot、Versum、Fujimi):在地化瓶頸
- **被動元件**(國巨 2327、華新科 2492):鈀 + 銀 + 鎳 上漲壓力
- **PCB**(臻鼎 4958、欣興 3037、南亞電 8046):銅箔 + 樹脂 上漲
- **電池 / 電池材料**:鴻海 2317、台塑新智能 + 立凱電能、台杉投資

**台灣戰略機會**(L1-B 候選):
- 礦物回收(電池回收 + 貴金屬回收):中鋼 + 光洋 + 凱鴻 + 國巨 旗下
- 加工本土化:中油 + 中鋼 + 台塑 + 化工業 / 半導體材料在地化

**間接影響**:
- **半導體 capex**:礦物價格波動 → 設備訂單時點
- **汽車電子**:車用半導體景氣 與 鋰/銅/稀土 同向
- **國防(中鋼 + 台船 + 漢翔 2634)**:戰略物資 capex 上升

**時間錨**:
- **2025-2030**:「去中化」投資高峰期,台股半導體材料類股 capex 受益
- **2030-2035**:回收產業起飛,2025 起 4-5 家上市,台灣「電池回收」IPO 區段
- **2035-2055**:本土加工 vs 回收 的雙軌成熟
