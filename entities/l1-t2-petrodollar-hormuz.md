# L1-T.2 石油美元與霍爾木茲

> 本頁從 L1-T multi paper 抽出，保留原始敘事與時間錨；對交易的解讀只是研究假說，不是可獲利確認。來源資料的 2025–2026 數字仍需逐項重查，故 confidence 不升 high。

## 三層 framework 讀法

- **MCP 層**：目前可用來檢查事件、資金與市場是否同步；不能把單次快照當成 50 年結構的證明。
- **學術層**：支持物理／人口／技術機制，但通常滯後，不能給出短線時點。
- **barbaric signals 層**：追蹤出口禁令、能源價格、capex、政策與人口公告；這是散戶尋找 72 小時解讀差的入口。

## 研究漏洞

- 本頁把長期結構與短期市場傳導放在同一個 paper 中，兩者時間尺度不同；後續必須用 L2／L3 資料拆開驗證。
- 「必然路徑」描述方向，不代表每個中間節點必然發生；任何跳躍都要保留 contested 可能。

# L1-T.2 — 石油美元結算權(50 年內美元能源支柱)

> **本檔 v0.1 → v0.2 重寫(2026-07-15)**:kaecer 指出「Step 4 太表象、缺上下游衝擊鏈條」。
> 重寫後以 **2026/2/28 美以聯手攻擊伊朗 → 霍爾木茲封鎖**(Bloomberg、CSIS、IFPRI 同步報導的真實事件)
> 為核心樣板,把「石油結算權」從抽象貨幣議題還原成 **物理衝擊 → 化學鏈條 → 終端消費** 的完整產業鏈。

## Step 1 現況(2026 真實事件快照,非假設情境)

### 1.1 霍爾木茲物理衝擊(2026/2/28 至今)

- **2026/2/28 美以「Operation Epic Fury」聯手打伊朗**,伊朗革命衛隊 3/1 宣布封閉霍爾木茲海峽(SRF / Tasnim 通訊社),2026/3/10 起布設水雷,3 艘商船被擊中,美軍反擊布雷艦但拒絕商船護航請求(Reuters 2026/3/10、NYT 2026/3/10、CSIS 2026/3/11)
- **流量缺口**:IEA 估全球油流 -1100 萬桶/日(短期峰值 -1840 萬桶/日,沙國 Yanbu 改走 +360 萬桶/日、UAE Fujairah +70 萬桶/日、IEA 釋儲 +200 萬桶/日、浮倉釋出 +100 萬桶/日)
- **油價**:WTI 期初 $63(2026/2/27)→ 衝擊期高點 $74.70 → 一個月後維持 $90-110(Bloomberg 引用 IEA)
- **航運 VLCC 中東至東北亞運費**:衝擊期 **+300-400%**(業界消息,TankerTrackers)
- **Qatar Ras Laffan LNG 廠被打擊**:卡達 LNG 出口能力下降約 15-20%(CNBC 2026/3/18)
- **Iran Kharg Island(佔伊朗原油出口 90%)受損**:伊朗原油出口能力下降約 50%

### 1.2 結算權現況(仍是美元主導,但壓力升溫)

- **OPEC+ 仍約 80% 原油以美元計價**(2024-2026 多源研判)
- **俄油 80% 已非美元結算**(2022 SWIFT 切斷後,人民幣/盧布/港幣/阿聯酋 dirham)
- **沙特 2024 與中國**:人民幣結算佔沙國出口中國 ~15-25%(早期試點,沙國主權基金 PIF 2024 首次發行人民幣債)
- **CIPS**(人民幣跨境支付系統):2024 Q4 月結算量 ~RMB 11 兆,SWIFT 占比仍 < 5%
- **央行美債持有占比**:2024 Q3 各國外匯存底中美元資產 ~58%(vs 2000 71%)
- **央行黃金持有佔比**:2024 ~13%,連 3 年突破 1000 噸/年(WGC 數據)

### 1.3 衝擊放大鏡 — 一個數字看出全球暴露度

> **「霍爾木茲海峽單一水道,佔全球貿易 20% 石油 + 20% LNG + 35% 尿素 + 30% 磷酸鹽 + 50% 硫黃」**(CSIS 2026/3/11 引 FT、EIA、IFA 數據)
>
> **這不是「石油問題」,這是「全球農工業基礎設施問題」** — 衝擊從原油出發,沿「原油 → 運費 → LNG → 氨 → 尿素 → 糧食/塑膠/紡織」12+ 個節點連鎖傳導,每節都放大一次。

## Step 2 前提(50 年歷史軌跡)

| 年代 | 事件 | 與 L1-T.2 的意義 |
|------|------|---------------------|
| **1944** | Bretton Woods:美元掛黃金 | 建立美元霸權的起點 |
| **1971** | Nixon 關閉黃金兌換窗口 | 美元從「金本位」轉向「實物錨(石油)」 |
| **1973** | 美沙秘密協議:沙國只以美元計價石油 | 石油美元正式確立(同年第一次油危機,4x 漲幅) |
| **1979** | 蘇聯入侵阿富汗、美沙安全聯盟強化 | 石油美元綁定美國安全保障(同年第二波油危機) |
| **1986** | 沙國淨產量戰 → 油價從 $30 → $10 | OPEC 控制力下降,但結算權未動搖 |
| **1990** | 伊拉克入侵科威特 → 油價 $40(當時新高) | 第一次「霍爾木茲軍事威脅」直接影響全球油價 |
| **1999** | 歐元啟動;2000 薩達姆宣布以歐元計價石油 | 「石油換美元」威脅的代價:2003 美入侵伊拉克 |
| **2008** | 油價 $147(歷史峰值) | 頁岩氣革命啟動、再生能源投資熱潮 |
| **2010** | 中國超越美國成為全球最大石油進口國 | 需求側結構翻轉,「石油買家」開始有議價權 |
| **2014** | 美頁岩油爆發、沙國拒減產 → 油價崩 | 「石油美元」受頁岩威脅,但結算權未變 |
| **2018** | 中國上海原油期貨掛牌 | 「石油人民幣」起點,但佔比仍 < 5% |
| **2020** | COVID + 沙俄減產協議破局 → 油價負值 | OPEC+ 重組,沙國承受財政壓力(2020 赤字 12% GDP) |
| **2022** | 俄烏戰爭、G7 油價上限 $60 | 西方對俄油金融制裁的「前置實驗」 |
| **2023** | 沙國加入 BRICS+、金磚擴容討論「去美元結算」 | 美元結算權首次出現政治層次威脅 |
| **2024** | 沙國 PIF 首次發行人民幣債 | 主權層級的「對沖美元」 |
| **2026/2/28** | **美以「Operation Epic Fury」打伊朗,霍爾木茲封鎖** | **「金融武器化」的物理對應版:**「能源武器化」 — 美元結算權的真正威脅從「貨幣替代」轉成「物理斷鏈」 |

**雙重轉折觀察**:
1. **2022 俄烏制裁讓非西方國家看到「美元資產可被凍結」** → 央行多元化(黃金 3 年爆買 3000+ 噸)
2. **2026 霍爾木茲封鎖讓西方國家看到「能源供應可被物理中斷」** → 不再能保證「美元能買到油」
3. **兩條線匯合**:**美元結算權從「金融問題」升級為「能源 + 金融 + 軍事」三重問題** — 美國必須同時維持金融霸權 + 能源可達性 + 海軍控制力,任一條鬆動都會讓其他兩條崩潰

### 4.3 利害結構驗證(對應 v0.3 §2 篩選 SOP)

1. **誰受益?**
   - **OPEC+ 短期**:油價 $90+ 維持財政
   - **美頁岩油商**:價格回到 $70+,capex 重新啟動
   - **沙 + 阿聯酋 國家主權基金**:油元再投資
   - **加拿大 + 巴西 + 圭亞那 原油**(非中東 OPEC,直接取代)
   - **澳洲 LNG + 美 LNG**:中東供給缺口被西方 LNG + 美國 LNG 取代
   - **中 / 俄 結算系統**:CIPS + SPFS 擴張加速
   - **黃金 + 比特幣 + 數位貨幣**:不確定性溢價
   - **替代能源加速者**:核能 + 再生 + 電池儲能 capex
2. **誰受害?**
   - **全球農民 + 食品消費者**:印度、巴基斯坦、孟加拉、埃及、北非、巴西(糧食 + 化肥雙重壓力)
   - **依賴進口油氣國**:日本(100%) + 韓國(~95%) + 台灣(99% 火力) + 印度 + 東南亞
   - **歐洲**(本來依賴俄氣,現依賴中東 LNG):雙重「能源武器化」受害者
   - **航空 + 海運 + 陸運**:燃油 + 保險 + 繞行成本(好望角航線多 14 天)
   - **塑化 + 紡織 + 包裝 + 肥料下游**:全部需求壓縮
   - **中東國家財政**(若衝突持續):伊朗本身崩潰、伊拉克被波及、葉門胡塞威脅紅海(本來就在威脅,現在強化)
   - **美元儲備依賴者**:若繼續累積美債 → 美元貶 + 實質購買力下滑
3. **利益結構能否持續?**(三段時間)
   - **短期(0-12 月)**:OPEC+ 油價優勢、頁岩油加速、糧食短缺 ─ 受害者是「消費者」
   - **中期(1-5 年)**:能源基礎設施重組(西方 LNG + 核能 + 再生)、能源結算多元化加速
   - **長期(5-30 年)**:化石能源需求峰值已過(IEA 2024 NZE)、結算權多極化是「不可逆結構」
4. **表象 vs 結構**:
   - **表象**:「油價 $74.70 高點是短期事件,等 OPEC+ 釋儲就會回穩」
   - **結構**:每一次物理衝擊(1973、1979、1990、2022、2026)都讓結算權多元化「真正跨過一個台階」
   - → **L1-T.2 的必然性不在「石油美元會消失」,而在「依賴度必然下降」**

## Step 5 結果(美中台日 — 結合霍爾木茲衝擊)

### 5.1 短期(2025-2030)— 已被 2026 事件驗證

## Step 8 對台股傳導(**v0.2 全面擴充,以 2026 真實鏈條為主**)

### 8.1 直接被霍爾木茲衝擊的台股族群

#### 8.1.1 塑化 + 化纖 + 包材(原油漲價直接受害)

- **台塑集團**(6505 台塑化、1304 台塑、1303 南亞、1326 台化):中東原油 99% 進口,油價 $63 → $90 + 運費 3-4x = 短期成本暴增
- **化纖**(1457 大東、1711 大統、1717 長興、1718 中纖、1459 聯發):聚酯 + 尼龍 + 壓克力 都是石油煉製副產品
- **合成橡膠 / 輪胎**(2105 正新、2106 建大):丁二烯 + 碳黑 = 原油副產品
- **塑膠袋 / 包裝**(1302 台聚、1307 三芳、1308 南亞電路板、1312 國喬):PE / PP / PVC 跟隨原油
- **農化**:台肥 1722(直接受衝擊,中國尿素價 + 國際尿素價)

#### 8.1.2 LNG + 燃料 + 電力(台灣 99% 進口能源)

- **中油 + 台電**(無上市):LNG 採購成本 + 燃料附加費上修;桶裝瓦斯 + 工業用 LPG + LNG(發電);**電價 2026 已見壓力**
- **油品銷售**(台塑化 6505 + 統一超 2912 油品事業部):零售油價波動劇烈
- **國防 + 戰備儲油**(中油):戰略儲油政策可能提前加速

#### 8.1.3 航運(雙面影響)

- **長榮 2603 + 陽明 2609 + 萬海 2615**:
  - 短期利:**VLCC / Suezmax / Cape 運費 +300-400%**;但台灣航運以貨櫃為主,直接運費正面影響小
  - **主要繞行成本**:紅海 → 好望角航線多 14 天 → 燃油 + 船舶週轉降低,運價自然上漲
  - 中期利:**IMO 2027 碳稅 + 俄油制裁 = 船舶 capex + 收益模型改寫**

#### 8.1.4 食品 + 農業(下游最末段)

- **統一 1216 + 大成 1210 + 味全 1201 + 卜蜂 1215 + 愛之味 1217**:
  - 玉米 + 大豆 + 小麥 + 棕櫚油 全部受衝擊(荷姆茲衝擊 + 巴西甘蔗改乙醇 + 美國春耕壓力)
  - **食品通膨 2026/4-7 預估 +5-10%**(原料 + 運費 + 飼料 + 包裝 四重壓力)
  - **股價短期正面**(轉嫁能力強的廠商),長期受惠(抗通膨剛需)

#### 8.1.5 半導體(被忽略但極重要)

- **台積電 2330**:原料(矽晶圓 + 蝕刻氣體 + 光阻) 不直接受油價影響,但 **Helium(卡達佔全球 30%)** 短缺!

  - **TSMC 在 2026/3 已備 6 個月庫存**(媒體報導),但市場會提前反應估值
- **2329 + 2363 + 2379 矽晶圓 / 封測 / 光罩**:次級衝擊,觀望

## 收尾:L1-T.2 v0.2 升級要點

1. **從「貨幣結算權」單線 → 「物理 + 金融 + 軍事」三重議題**:霍爾木茲 2026 事件證明,美元結算權的真正威脅從「人民幣取代」變成「石油買不到」
2. **從「趨勢描述」→「事件衝擊鏈條展開」**:12 節物理鏈 + 8 節結算鏈,把抽象貨幣議題還原成產業衝擊
3. **從「點名 5 個國家」→「2026 真實事件中所有曝光國連鎖」**:印度、巴西、巴基斯坦、孟加拉、撒哈拉以南非洲 全部被驗證
4. **從「台股點名」→「台股權族群量化敏感度」**:塑化 + LNG + 食品 + 半導體 + 金融全部展開
5. **保留 v0.1 的「美元結算權稀釋」多極結算長線結論**(這仍然正確),但加上「短期霍爾木茲衝擊」的具體路徑圖

**v0.2 校驗時點**:
- 若 2026/6 後霍爾木茲仍未恢復 → 進入「1970s 級油危機」基準情境
- 若 2026/4-5 恢復通行 → 進入「短期震盪 + 中長期趨勢不變」基準情境
- 目前預估:**2026/4-5 部分恢復**(美軍護航 + OPEC+ 增產 + 各國釋儲),但「化學鏈條」(化肥 + 糧食 + Helium)影響延續到 2026 Q3-Q4
