### 3.2 我的讀

4 個 narrative events 中 3 個是 bullish（conf 加權平均 ≈ 0.91），但現實 TAIEX -6.47%、regime RISK_OFF、stress 一度 alert、capital_flow bearish — **narrative 嚴重滯後於現實**。

更有問題的是：narrative_get_events 把 `confidence=0.95` 給 AI_capex，**但同一個 narrative engine 在 hit_rate 0.81 的歷史前提下，仍然沒把這一天的 TAIEX -6.47% 標成「敘事失敗」**。

這是 H1 **最關鍵的失敗模式**：**narrative confidence 不是事件真實發生機率，而是「模型對自身敘事的信心」**。把 0.95 讀成「AI capex 敘事有 95% 機率繼續推升台股」是過度詮釋。

## 4. H2：機構買而融資不升

> **H2**：當「本土機構（投信 + 自營商）明顯買超」但「融資餘額不升甚至下降」時，可能是「土洋對殺 + 散戶去槓桿」的混合訊號，不是純看多。

| 投信 | +0.30 | bull（小幅） |
| 自營商 | -31.98 | **bear**（大幅賣） |
| 投信 + 自營商（同日同向？） | **方向分歧** | 投信買、自營商賣 → 不是 H2 典型場景 |
| 融資餘額 | 5,879.6 億（change_pct -4.49%） | **降槓桿** |
| 借券餘額 | 2.363（change_pct +33.79%） | **借券暴增** |

### 4.2 我的讀

**H2 在 7/17 不成立**。原因是：
- H2 假設是「**本土機構**買，散戶不跟」；但 7/17 是「**投信買、自營商賣**」 — 自營商不是被動買方，它的 -32 是巨大賣壓。
- 而且散戶的「raw_value +29.30」與融資餘額 -4.49% 看起來矛盾 — 但 raw_value 應該不是融資，是某種代理變數（可能是借券賣出收入、自營商對作、或其他）。需要驗證 `raw_value` 的計算口徑。
- **借券 +33.79%** 才是 7/17 真正的異常訊號：散戶可能在「融資回補 + 借券放空」同時進行（軋空準備？或避險？）

### 4.3 信心與限制

- **H2 verdict**：7/17 樣本不支援。投信與自營商同向假設在 7/17 破功。
- **真正的訊號是「借券暴增 + 融資降」**，這要回去查 2024-2026 歷史同期數據，看是不是特定事件的指紋（例如：除權息旺季避險、ETF 重新平衡、關稅預期避險空單）。
- **raw_value 口徑必須驗證**，這是 H2/H3 共同的前提。

## 5. H3：被動／套利資金誤判

> **H3**：當 narrative 把「被動買盤 / 套利倉」當成主動方向意圖時，會誤判趨勢強度。

### 5.1 raw evidence

| 訊號 | 數值 | 解讀 |
|---|---|---|
| retail_institutional_divergence template | hit_rate 0.6 | template 已註冊 |
| 散戶 +29.30、外資 -12.72、投信 +0.30、自營商 -31.98 | 分歧 4 個主體方向 | 已觸發 template 條件 |
| 借券 +33.79% | 暴增 | 但 template 沒說這是觸發條件之一 |
| 融資 -4.49% | 下降 | template 條件之一（Z > 1.5 才是過熱），7/17 融資下降而非上升 — 條件未觸發 |

### 5.2 我的讀

7/17 觸發的是「**散戶機構分歧**」（retail_institutional_divergence），不是 template 描述的「散戶過度樂觀 + 機構賣超」。原因是：
- template 假設「融資餘額 Z > 1.5」，但 7/17 融資是**下降**的 — 觸發條件反向。
- 真正的 pattern 是「**融資下降 + 借券暴增 + 機構賣**」 — 這比較像「**散戶去槓桿 + 對沖放空**」，是**對下跌的確認**，不是對過熱的警告。

這直接打臉 H3 的初衷：template 設計時假設「散戶 = 槓桿過熱 = 反指標」，但實務上「散戶降槓桿」反而是更強的看空訊號。

**H3 在 7/17 確實成立，但方向與 template 預期相反**：template 設計的「散戶過熱」沒觸發；真實觸發的是 template 沒覆蓋的「散戶去槓桿 + 借券放空」。

### 5.3 信心與限制

- **H3 verdict**：通過，但**觸發條件與 template 預期不同**。
- **未驗證**：借券 +33.79% 在 2024-2026 歷史同期是否常見。如果常見，可能是季節性；如果罕見，才是真實避險空單。
- **未驗證**：retail_raw_value +29.30 的計算口徑。如果它把「融資賣出成交金額」也算進去，那 +29.30 跟融資 -4.49% 就不是矛盾。
