# Fin-Skills 32 SK 預評索引

> 這是 atlas-skill-inbound 的「優先序決策錨」。

## §1 預評標準

引:ATLAS_METHODOLOGY.md §五策略矩陣(策略三分類 = **跟隨聰明錢 / 事件套利 / 資金對抗**) + §六散戶跟隨座標。

| relevance | 定義 | 評估依據 |
|-----------|------|---------|
| **HIGH** | 直接對位現有 atlas-mcp tool + 散戶可一句話理解 + 對位 mission「找信息差/找漏洞」 + 對位憲章 §五**跟隨聰明錢 / 事件套利 / 資金對抗 三分類** | 例如 SK-16 多空十分位數（atlas `backtest_signals` 可驗、散戶懂「top 10% / bottom 10%」、對位「找漏洞」=看多空是否真的能賺、歸類**跟隨聰明錢**） |
| **MED** | 學術骨架清楚,需程式轉譯成 atlas 表達;散戶化難度中 | 例如 SK-04 Huber 損失、SK-09 PLS |
| **LOW** | 學術研究為主(複雜迴歸/RL/量子);對 atlas 用戶非必要;散戶不易理解 | 例如 SK-27 量子網路、SK-24 PPO |

**注**:LOW 不是「不寫」,而是「最後寫」——先用 HIGH/MED 把 mission 主線鋪好,
LOW 留作後續 niche 主題（量子/RL）或有明確需求時補。

**新加 §1.1 策略類別(預)欄**(2026-07-30 對位憲章 v1.0):
- **跟隨聰明錢**:主追「聰明錢」(外資+投信+公司派)信號,典型信號 = 外資連 3 日買超、AI 鏈轉強、外資期貨未平倉多單
- **事件套利**:鎖定可預測事件(ETF 調整、MSCI 季度、除權息、營收公告),事件前布局、事件後獲利
- **資金對抗**:在低迷期末端布局,轉折出現後收割(典型:融資大減 + 公股持續買超時的對抗策略)

## §3 第一輪優先序推薦（對位 kaecer 既有 _inbox.md）

**[_inbox.md](_inbox.md) 2026-07-29 已列第一輪**:SK-16、SK-18、SK-20、SK-29（4 個 HIGH）

我的排序建議:
1. **SK-16**（多空十分位數投資組合）——對位 mission「找漏洞」最直接,atlas-mcp `backtest_signals` 真能驗
2. **SK-29**（滾動窗口回測模擬）——任何策略都要先過這個,放第二讓後續 SK 都可驗證
3. **SK-18**（因子 Alpha）——前一輪的「找漏洞」深化,用 `risk_get_metrics` 對位
4. **SK-20**（規模分組穩健性）——找漏洞的反證工具,「小公司效應還在不在」是 mission 級判斷

**建議 quota 3/天**（kaecer 已拍板降標 A 方案）的話:
- 第 1 天:SK-16 + SK-29 + SK-18 = 3 頁,湊齊第一輪可執行的 pipeline:因子 → 多空 → 回測 → Alpha
- 第 2 天:SK-20 + SK-03 + SK-19（若 SK-01 已有 Skeleton 可繼續驗證切割與成本）
- 第 3 天起:依 _inbox.md 後續排程輪下一批

但需注意:**quota 3 是純寫頁數,不含跨頁三層驗證(L1 格式 + L2 對位 + L3 端點)**
L3 端點驗證需跑 MCP,單次頁寫完不一定能在同 quota 內跑完——這是個待解決的結構問題。
