# 資金勢力分類學修正版

> **狀態：已結案（2026-08-22，spec 3+2+2 取代）。** 本頁保留供 audit 對照，不宣稱已是 manifest E05 的正式實作規格。

## 核心修正

現行「七大資金勢力」混合了兩種不同東西：

- **資金主體**：真正具有資產負債表、投資 mandate 或交易權限的參與者。
- **觀測代理／輸入特徵**：用來推測資金方向的市場資料或價格反應。

期貨與 TSM ADR 不是獨立資金主體。若把它們和外資並列計算共振，會產生重複計權：外資期貨、外資現貨、TSM ADR 可能同時反映同一個全球資金決策。

## 建議正式分類

### 主體：5 類

1. **外資**
2. **投信**
3. **自營商**
4. **官股行庫**
5. **散戶**

共振模型只在這 5 個主體間計算：

- 同向：主體間的方向共振。
- 對立：主體間的資金分歧。
- 不明：資料缺失、時點不一致或交易目的無法識別。

### 外資的觀測維度：不是獨立勢力

- **現貨買賣超（T86）**：較接近已實現配置，屬落後確認。
- **台指期未平倉（TAIFEX）**：較接近方向先驗，但可能包含避險、套利與展期，不能單獨等同看多／看空。

這兩個維度都掛在「外資」底下，不能各自增加共振票數。

### 情緒特徵：輸入變數，不是勢力

- **TSM ADR 折溢價與漲跌**：台股科技風險偏好／隔夜情緒代理。
- **VIX**：全球風險厭惡特徵。
- **USD/TWD**：匯率與外資換匯壓力特徵。

這些特徵可以調整外資方向的先驗，但不能直接算作一個新的買方或賣方。

## 情緒調整層（kaecer 2026-08-22 收編）

> 收編裁決：VIX / USD_TWD 作為外資方向先驗的**調整特徵**,不進共振投票。此為 wiki 知識模型層設計;atlas spec 未含此層且不可改,atlas 端是否實作另軌（勿假裝已實作）。

- **VIX**：全球風險厭惡特徵。外資方向先驗調整：VIX 高檔急升 → 外資先驗置信度下調（防禦/撤離情境）。
- **USD/TWD**：匯率與外資換匯壓力特徵。台幣急貶 + 外資賣超同現 → 先驗強化;台幣貶但外資買超 → 先驗弱化（可能是出口商結匯等其他驅動）。
- **調整規則（wiki 層建議）**：情緒特徵只調整先驗**方向置信度**,不改變主體共振投票數;缺資料時不調整（對位 E05「缺資料時不補零」原則）。

## 為什麼這是重要漏洞

上一版活體觀測中，TSM ADR 被給予 30% 權重，而外資是 0%。這會造成：

- **代理壓過主體**：市場情緒代理的權重高於實際資金主體。
- **同源資料重複計算**：ADR 與外資、台股科技股可能共同反映同一個全球風險因子。
- **共振失真**：一個主體的不同載體被錯算成多個獨立力量。
- **反應與因果顛倒**：ADR 是預先情緒訊號，不代表外資已經在台股現貨完成交易。

## 暫定計算原則（待簽核後才落 E05）

### 1. 共振層

只計算 5 個主體的標準化方向：

```text
resonance = f(foreign, mutual_funds, dealers, government_banks, retail)
```

### 2. 外資方向先驗

外資方向不是由 ADR 取代，而是由外資自身的兩個觀測維度組合：

```text
foreign_prior =
    w_spot * z(T86_foreign_spot)
  + w_futures * z(TAIFEX_foreign_oi)
```

其中 `w_spot`、`w_futures` 必須以歷史回放校準，不能先硬編固定值。

### 3. 情緒調整層

```text
foreign_adjusted_prior = foreign_prior
  + g(TSM_ADR, VIX, USD_TWD)
```

`g()` 的作用是調整信心或風險狀態，不是創造第六、第七個勢力。

### 4. 缺資料時不補零

- T86 缺失 ≠ 外資中性。
- TAIFEX 缺失 ≠ 沒有期貨部位。
- ADR 缺失 ≠ 情緒中性。
- 應使用 `unknown`／資料品質旗標，避免缺資料被誤算成 neutral。

## 與原七類分類的關係

原頁面的七類分類仍保留為「行為目的研究草圖」；本頁是更高優先級的「勢力計數與共振建模修正版」。兩者不應互相覆蓋：

- **五主體分類**：用於 manifest E05 的正式共振計算。
- **七類行為分類**：用於研究主體內部的方向倉、套利倉、被動倉、造市倉與避險倉。

這樣可以同時保留「誰在動」與「為什麼動」，但不把代理冒充成主體。
