# 台股籌碼面分析手冊

> **一句話**：台股籌碼面分析追蹤外資、投信、自營商[[concepts/taiwan-money-flow-seven-institutional-buckets|三大法人]]的資金流動，配合 atals 平台的[[concepts/taiwan-money-flow-seven-institutional-buckets|七維錢潮雷達（3+2+2 分層）]]與融資融券、借券等散戶代理指標，判斷市場資金的真實方向。

## 一、籌碼面分析的基本概念

### 1.1 為何要分析籌碼

```
價格反映「預期」
成交量反映「實際交易」
籌碼反映「誰在交易」
```

- **基本面**：回答「公司賺不賺錢」
- **技術面**：回答「價格走勢如何」
- [[concepts/taiwan-chip-flow-analysis|籌碼面]]：回答「誰在買、誰在賣、為什麼」

在台股市場，籌碼面尤其關鍵，因為：

1. **自然人比重高**：市場參與者結構以散戶為主，**法人動向對個股有方向性帶動**
2. **逐筆交易 + 盤後揭露**：每日盤後揭露[[concepts/taiwan-money-flow-seven-institutional-buckets|三大法人]]買賣超
3. **ETF 與投信作帳**：季底作帳行情為台股顯著現象
4. **資金動能領先於股價**：M1B、外資買賣超等是領先指標

### 1.2 三層籌碼分析架構

```
第一層：總體（市場籌碼）
   ├── 外資整體買賣超
   ├── 投信買賣超
   └── 自營商買賣超

第二層：結構（行為籌碼）
   ├── 融資融券餘額
   ├── 借券賣出餘額
   └── 當沖比例

第三層：個股（集中度）
   ├── 集保庫存（千張大戶持股）
   ├── 董監持股比例變動
   └── 外資持股比例（20%、50% 界線）
```

## 二、atlas 七維錢潮雷達（3+2+2 分層）

> atlas 平台的資本流動分析模組採用「**七維錢潮雷達（3+2+2 分層）**」架構，分層規則為 **共識層（官方 3 個）→ 行為層（代理 2 個）→ 訊號層（領先 / 跨市場 2 個）**。

### 2.1 共識層：3 個官方力量（first-party）

| 維度 | 角色 | 資料來源 | 頻率 |
|------|------|----------|------|
| **外資** | 台股最大法人，影響權值股 | 證交所每日盤後 | T+0 |
| **投信** | 國內基金 + ETF 發行商 | 證交所每日盤後 | T+0 |
| **自營商** | 證券商自有資金 | 證交所每日盤後 | T+0 |

> atlas 共識投票邏輯：以這 3 個官方力量為主。

### 2.2 行為層：2 個代理指標（proxy）

| 維度 | 角色 | 為何是代理 | 限制 |
|------|------|------------|------|
| **政府基金** | 國安基金 + 公股 | 進場時機與退場時機非市場化 | 缺乏標準化頻率 |
| **散戶** | 自然人買賣 | 透過程式 / 數據推估（並非官方直發資料） | 屬推算值 |

### 2.3 訊號層：2 個領先 / 跨市場訊號

| 維度 | 角色 | 訊號意義 |
|------|------|----------|
| **外資期貨未平倉淨多 / 空單** | 期貨部位避險情緒 | 空單大增 = 避險壓力升高 |
| **台積電 ADR（TSM）** | 美國時段提前揭示台積電定價 | 預判台股 ADR 表現 |

### 2.4 共識投票規則

```
共識層（3 個）表決
   → 若 ≥ 2 票同向 → 形成「共識多 / 空」訊號
   → 行為層（2 個）作為加權 / 反證
   → 訊號層（2 個）作為領先 / 背離訊號
```

LLM agent 在引用 atlas 報告時，可標註：

- 「**官方 3 票共識**」→ 主流訊號
- 「**代理 2 票**」→ 行為面佐證
- 「**訊號 2 票**」→ 前瞻 / 跨市場參考

## 三、三大法人系統

### 3.1 外資（Foreign Investors）

#### 重要性

- **持股市值**：佔台股流通市值約 40–45%（含僑外資）
- **單日成交值**：佔大盤 25–35%
- 是**單一最大法人**，直接影響權值股動向

#### 每日盤後資料

```
現貨買賣超（最重要）
期貨未平倉淨多 / 空單
選擇權未平倉
借券賣出餘額
```

#### 觀察重點

- **連續性**：連續買超天數 > 連續買超總金額
- **幅度**：單日買超 100 億以上為「大動作」
- **與股價背離**：股價漲但外資賣超 → 法人撤退訊號

### 3.2 投信（Domestic Investment Trust）

#### 角色

- **共同基金 + ETF 發行商**
- 投信動作代表「主動選股者」與「**季底作帳**」需求

#### 行為模式

- **順勢跟單**：常在多頭中加碼至滿水位
- **季底作帳**：季底（3、6、9、12 月底）前常拉抬持股 → 帳面績效
- **年底作帳**：12 月底更明顯

#### 觀察重點

- **連續買超標的**：投信鎖碼股（高一致度）
- **季底前 5–10 日**：作帳行情啟動點
- **與股價反向關係**：投信買超 + 股價未動 = 鎖碼

### 3.3 自營商（Dealers）

#### 分類

| 分支 | 角色 |
|------|------|
| **自營（Proprietary）** | 用自有資金下單 |
| **避險（Hedge）** | 期貨部位避險，可能為負向持股 |

#### 自營商特性

- **短線交易者**：當沖、隔日沖主力之一
- **避險部位**：期貨空單通常要現貨多單對沖
- **市場訊號**：
  - 避險空單大量 = 預期指數下跌的避險
  - 自營多單大增 = 看多現貨

#### 觀察重點

- **避險 / 自營比**：若避險空單 > 自營多單 → 整體偏空
- **日內波動參與度**：對當沖稅率敏感（稅率降 → 交易增）

## 四、外資的籌碼面細部分析

### 4.1 外資現貨買賣超

#### 觀察面

- **單日金額**：100 億以上為訊號級別
- **連續性**：連續 5 日 / 10 日同向為趨勢訊號
- **累計同向天數**：連續買超創新高 = 強勢多頭

#### atlas 上的策略

- **foreign-3day-inflow**：3 日連續買超（如超過某門檻）
- **foreign-5day-inflow**：5 日版本（更強）
- **foreign-rotation**：由賣轉買

### 4.2 外資期貨未平倉淨多單

#### 計算

```
外資期貨未平倉淨單 = 未平倉多單 − 未平倉空單
```

#### 觀察意義

- **淨多單 > 10 萬口**：多頭氣勢
- **淨空單 > 5 萬口**：避險壓力
- **由多轉空**：警訊
- **與現貨背離**：現貨買超 + 期貨空單增 = 避險（暗示對未來不確定）

### 4.3 外資借券賣出餘額

#### 觀察意義

- **借券賣出餘額上升**：
  - 空方力量累積
  - 通常搭配特定個股賣壓
- **借券賣出餘額下降**：
  - 空方回補或還券
  - 軋空動能醞釀

#### 警戒值

| 區間 | 含義 |
|------|------|
| 餘額歷史前 30% | 空方氣勢強 |
| 餘額歷史前 10% | 過熱，反轉風險 |
| 餘額 < 1 萬張 | 空方撤退 |

### 4.4 外資持股比例

#### 重要界線

- **20%**：上市櫃公司外資持股上限（多數公司）
- **50%**：達到此水位 → 可能被特殊列管
- **100%**：理論上限

#### 行為觀察

- **外資持股上升**：長期看好
- **外資持股下降速度**：較「總額」更具參考性
- 個股外資持股比 30% 以上：實質外資主導個股方向

## 五、散戶指標

### 5.1 融資餘額（Margin Balance）

#### 重要性

- **台股最重要的散戶指標**
- 融資餘額 = 散戶借錢買股的金額
- 反映**散戶的槓桿使用程度**

#### 解讀

```
融資餘額上升 + 股價上漲 → 多頭市場正常延伸
融資餘額暴增 + 股價盤整 → 多頭過熱
融資餘額下降 + 股價下跌 → 多殺多
融資餘額急速下降 → 斷頭潮 → 市場底部訊號
```

#### atlas 策略對應

- **margin-balance-extreme**：融資餘額達到極端值（參見[[concepts/atals-strategy-taxonomy|融資餘額極端]]策略）
  - 過高 → 反轉訊號（散戶過度槓桿）
  - 過低 → 反彈訊號（散戶絕望）

### 5.2 融券餘額

#### 解讀

- **融券餘額上升**：散戶看空
- **融券餘額 + 軋空訊號**：
  - 券餘高 + 股價突破關鍵壓力 = 軋空行情啟動
- **軋空警訊**：
  - 券空比高（融券 ÷ 流通籌碼）
  - 連續 5 日券增但股價無明顯下跌
  - **軋空訊號**：券增 + 價強不跌 → 軋空風險升高

### 5.3 當沖比例

#### 定義

```
當沖比例 = 當沖買進成交值 ÷ 總成交值
```

#### 解讀

| 比例 | 解讀 |
|------|------|
| < 30% | 正常市場結構 |
| 30%–50% | 當沖熱絡 |
| 50%–70% | 過熱，短線風險升高 |
| > 70% | 嚴重過熱，可能反轉 |

#### 注意

- 當沖比高時，**收盤價與真實方向可能脫節**
- 個股當沖比 > 50% 時，避免以盤中訊號進場

## 六、內部人 / 大股東持股異動

### 6.1 董監持股

- **規定**：
  - 上市櫃董監事有持股門檻（依股本規模）
  - 變動需申報（每月公告）
- **解讀**：
  - **董監大額增持** → 內部人看好
  - **董監大額申讓** → 內部人看淡、變現
  - **持續性**：單月可能為雜訊，連續 3 個月趨勢更具參考

### 6.2 大股東 / 集保庫存

- **集保庫存統計**：
  - **400 張以上大戶**（法人或實力派）
  - **20 張以下散戶**
- **解讀**：
  - **大戶增加 + 股價** → 實力派進場
  - **大戶減少 + 股價** → 實力派撤退
  - **散戶增加 + 股價漲** → 籌碼流向散戶 → 末期警訊
  - **散戶減少 + 股價跌** → 恐慌後籌碼集中 → 底部訊號

### 6.3 子公司或關係人持股

- **集團內子公司交叉持股**：
  - 母公司買進子公司股票 → 集團資本運作訊號
- **觀察**：
  - 同集團上下游交叉持股增加 → 集團鞏固控制權
  - 集團大幅減持 → 結構性調整警訊

## 七、本土法人撐盤（土洋對作）

### 7.1 「土洋對作」的概念

```
土 = 本土法人（投信 + 自營商）
洋 = 外資

土洋對作：外資賣 + 投信 / 自營買（或反向）
```

### 7.2 訊號意義

#### 情境 A：外資賣 + 投信 / 自營買

- 解讀：本土法人「**撐盤**」
- 注意：投信 / 自營通常規模較小，無法長期對抗外資賣超
- **若股價不跌**：可能為底部訊號
- atlas 策略名稱：**dealer-domestic-support**

#### 情境 B：外資買 + 投信 / 自營賣

- 解讀：本土法人「**減碼退場**」
- **若股價仍漲**：法人主力外移，但仍有上派空間
- **若股價反轉向下**：本土退場訊號強

### 7.3 應用建議

- **土洋同向**：強訊號（雙方一致看好 / 看壞）
- **土洋背離**：觀察後續誰會改方向 → 領先者具優勢

## 八、資金流向的判讀方法

### 8.1 綜合判讀流程

```
每日盤後檢查：
1. 外資三大法人買賣超（共同方向或背離）
2. 融資 / 融券 / 當沖變化
3. 借券賣出餘額變動
4. 個股集保大戶資料（每週 / 每月）
5. atlas 七維訊號變化（每日更新）
```

### 8.2 多空交叉確認

```
多頭訊號：
[ ] 外資連續 3 日買超
[ ] 投信連續 3 日買超
[ ] 融資增加但股價平（未失控）
[ ] 借券賣出餘額下降

空頭訊號：
[ ] 外資連續 5 日賣超
[ ] 融資餘額急速下降（斷頭潮）
[ ] 當沖比例過高（> 60%）
[ ] 借券賣出餘額歷史高位
```

### 8.3 籌碼面常見陷阱

#### 陷阱 1：當沖雜訊

- **當沖比例高時**，盤中「賣超」訊號多為當沖了結
- 解讀時應以收盤資料為主

#### 陷阱 2：被動買賣的「假動作」

- ETF 申購贖回的「現金買盤」記錄在外資，可能並非真實方向
- atlas 會區分「**主動 / 被動**」買賣

#### 陷阱 3：政策事件干擾

- 國安基金進場、投信季底作帳等事件，會讓「**真實方向**」模糊
- 應觀察連續性與結構，而非單日數據

#### 陷阱 4：個股特殊事件

- 增資、減資、私募、可轉債轉換等因素會影響個股籌碼
- 需檢視公司公告

#### 陷阱 5：產業輪動的時差

- 法人轉換持股需要時間
- 「**領先指標 vs 同時指標 vs 落後指標**」需區分

## 十、台股籌碼面特性總結

```
台股籌碼面 = 全球共性 + 台灣在地結構

關鍵點：
1. 七維錢潮雷達：3 共識 + 2 行為 + 2 訊號
2. 三大法人每日盤後揭露 → 當日即可解讀
3. 融資餘額 = 散戶核心指標，搭配 margin-balance-extreme 策略
4. 土洋對作與 dealer-domestic-support 為底部訊號參考
5. 借券賣出 + 融券為空方雙軌指標
6. 當沖比例過熱 (>60%) → 短期風險
7. 集保大戶變動為結構性 / 中長期訊號
```

LLM 在回答投資人問題時，建議將籌碼面與技術面、基本面**交叉運用**，避免單一指標決定結論。
