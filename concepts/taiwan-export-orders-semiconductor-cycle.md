# 台灣出口與半導體景氣（因果鏈第二層）

> **一句話**：本頁是憲章因果鏈第二層「台灣出口與半導體景氣」的補課頁——用「出口訂單、台積電月營收、半導體設備進口」三大月頻指標，把 L1 美股科技估值（SOX/NVDA）的需求訊號驗證成台灣基本面，再餵給 L3 外資買賣超解讀。2026-08-22 全庫掃描時此層近真空：出口訂單 0 命中、台積電月營收 0 命中 [2026-08-22 audit-fix]。

## 一、三大指標總表

| 指標 | 指標意義 | 公布節奏 | 判讀邏輯 |
|------|---------|---------|---------|
| 台灣出口訂單 | 基本面方向（憲章 L2 原文） | 經濟部統計處, 每月約 20 日公布前月值 [公布日為通識, 需驗證] | YoY 趨勢比單月絕對值重要 |
| 台積電月營收 (2330) | 產業鏈拉貨信號（憲章 L2 原文） | 每月約 10 日公布 [通識] | YoY 趨勢比單月絕對值重要 |
| 半導體設備進口 | 產能擴張預期（憲章 L2 原文） | 海關/國貿局統計 [管道需驗證] | 認列有滯後, 只當確認訊號 [需驗證] |

### 1.1 台灣出口訂單（外銷訂單）

- **意義**：接單統計, 領先出貨型出口統計, 反映台灣電子/資通訊產品的外部需求, 是散戶拿得到的官方月頻基本面數據。
- **公布節奏**：經濟部統計處每月約 20 日公布前月值 [公布日為通識, 需驗證]；官方網站新聞稿與統計表可查 [通識]。
- **判讀邏輯**：看 YoY 的 3 個月趨勢, 不看單月絕對值。電子類別（資通訊/電子零組件）與半導體鏈相關性最高, 但具體領先月數需量化 [待驗證]。

### 1.2 台積電月營收（2330）

- **意義**：台股權值龍頭月營收, 是「產業鏈拉貨信號」（憲章 L2）——AI/半導體需求最終要兌現成台積電出貨數字。
- **公布節奏**：每月約 10 日公布 [通識]；公開資訊觀測站與台積電官網投資人關係頁可查 [通識]。
- **判讀邏輯**：YoY 趨勢 + 與法說資本支出展望交叉。單月營收受工作天數、晶圓出貨時點干擾, 單月驚喜不足以改變方向判斷。
- **atlas 對位**：`stock_get_monthly_revenue`（個股月營收 YoY/MoM, 可選月份區間）已存在於 atlas-mcp tool catalog（117 tools）[2026-08-22 audit-fix 盤查], 可直接查 2330。

### 1.3 半導體設備進口

- **意義**：「產能擴張預期」（憲章 L2）——設備進口代表晶圓廠/封測廠把資本支出落地成產能。
- **公布節奏**：海關進出口統計 / 國貿局貿易統計 [管道需驗證]；公布日未確認 [需驗證]。
- **判讀邏輯**：設備進口與資本支出公告間有認列時點落差 [需驗證]；對散戶而言它比新聞標題慢, 適合當「確認」訊號而非領先訊號。

## 二、與因果鏈上下游的關係

```
L1 美股科技估值：SOX → 全球半導體需求信號；NVDA → AI 資本支出領先指標（憲章 L1）
   ↓ 全球需求定價
L2 台灣出口與半導體景氣（本頁）：把需求訊號驗證成台灣基本面
   ↓ 基本面支撐/證偽
L3 外資期現貨 + 匯率：外資是方向制定者（憲章 L3）
```

- **上游 L1**：SOX/NVDA 是「預期」端（日頻即時）；L2 是「兌現」端（月頻）。L2 的功用是驗證 L1 敘事有沒有真的變成台灣訂單。
- **下游 L3**：外資買賣超是「資金」端。L2 轉強 + 外資買超 = 基本面與資金同向（乾淨支撐）；L2 轉弱但 L1 強 = 敘事與基本面背離, 需警惕。
- **七時期對位**：月頻數據無法單獨判定時期（時期由日頻的 L1/L3/L4 判定）, 但可當「上升期持續性」與「高原期證偽」的月度檢查點。七時期為真值, RISK_ON/OFF/NEUTRAL 只是向下相容層（憲章 Phase 2 自動映射）。

## 四、散戶解讀

**最常踩的坑**：看單月 YoY 驚喜追價——某月出口訂單或台積電營收 YoY 大跳就進場, 結果常是低基期/高基期造成的單月假訊號。

**正確姿勢**：

1. 只對「3 個月 YoY 趨勢」動作——連續 3 個月同向才叫趨勢 [通識判讀原則]。
2. 月頻指標只做確認, 不做預測——方向由 L1（SOX/NVDA）與 L3（外資）的日頻數據決定。
3. 把每月 10 日（台積電營收）與每月 20 日（出口訂單）[公布日為通識, 需驗證] 放進行事曆, 公布後 1–2 天看市場如何消化, 不搶第一時間。
4. 與 [[skills/SK-31-ai-investment-cycle-2026|SK-31]] 設備鏈能見度（2026 Q3~Q4 設備鏈首次訂單能見度）交叉：訂單/營收趨勢 + 設備鏈能見度同向 = 景氣週期確認。
