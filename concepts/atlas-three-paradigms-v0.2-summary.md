# L/T/S 三範式摘要

- **L（鐵律）**：1 天到 18 月的事件必發生時間帶；找的是結構已經開始動、但市場還沒完成解讀的曙光。
- **T（微趨勢）**：0.5–3 年的制度、產業與資金趨勢；L 事件經 L2 收斂後，才有資格進入 T 的配置研究。
- **S（演化）**：不是單純盤整，而是訊號紊亂、路徑尚未收斂；工作不是硬猜方向，而是等 T1→T2→T3 收斂。

## 使用順序

`L 觸發 → L2 路徑選擇 → T 趨勢確認 → S 期間等待／防守 → T1/T2/T3 收斂後才評估交易`

## 與三層 framework 的對位

- MCP 層回答「現在資料顯示什麼」。
- 學術層回答「這個機制是否有可移植的物理／制度基礎」。
- barbaric signals 層回答「真實世界的政策、資金與利益是否已先動」。

三層 framework 不是 L/T/S 的替代品；它是判斷某個 L 事件是否正在轉成 T、或仍停在 S 紊亂期的檢驗工具。

## 未決問題

- L 的 1 天–18 月區間，需用事件回放校準，不宜當成固定統計保證。
- S 何時結束，必須明確定義「連續幾日」與「哪些 T1/T2/T3 狀態」才可測試。
