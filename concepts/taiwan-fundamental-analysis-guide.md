# 台股基本面分析手冊

> **一句話**：台股基本面分析採用「總經→產業→個股」由上而下框架，月營收年增率(YoY)與台積電(2330)[[concepts/taiwan-stock-market-structure|權值股與市場結構]]變化是散戶最容易切入的觀測指標。

## 一、基本面分析架構：由上而下（Top-down）

```
層級一：[[concepts/taiwan-financial-domain-model|總體經濟]]（Macro）
   ├── GDP 成長率
   ├── 利率政策（CPI、央行利率）
   ├── PMI 採購經理人指數
   ├── 貨幣供給（M1B / M2）
   └── 國際環境（美中、台美、Fed 政策）

層級二：產業分析（Sector / Industry）
   ├── 產業生命週期（成長期 / 成熟期 / 衰退期）
   ├── 上中下游結構
   ├── 供應鏈強弱
   └── 競爭格局（集中度、護城河）

層級三：個股分析（Stock）
   ├── 營收 / 獲利動能
   ├── 估值（PE、PB、PS）
   ├── 財務體質（負債、現金流）
   ├── 經營效率（ROE、ROA、毛利率）
   └── 治理結構（董監事、ESG）
```

LLM agent 在分析提問時，應優先採用**由上而下**推論，避免直接給定個股建議。

## 二、總體經濟指標與台股的關聯

### 2.1 GDP 成長率

- **資料來源**：主計總處季更新
- **與加權指數關係**：
  - 台股年線報酬與實質 GDP 成長率呈長期正相關
  - 當實質 GDP > 3%：多頭機率提升
  - 當實質 GDP < 2%：盤整或修正壓力增加

```
GDP 加速 + 企業獲利上修 → 牛市延續
GDP 放緩 + 企業獲利下修 → 熊市風險
```

### 2.2 CPI 與央行利率政策

#### 核心機制

```
CPI > 政策目標（2%） → 央行傾向升息 → 股市資金成本上升 → 估值壓力
CPI < 政策目標     → 央行傾向降息 → 市場流動性增加 → 估值提升
```

#### 台股利率敏感度

- **金融股**：升息利於壽險與銀行利差擴大
- **科技股 / 高 PE 股**：升息不利（折現率提高）
- **不動產相關**：升息不利
- **高股息 ETF**：升息後股息殖利率的相對吸引力下降

### 2.3 PMI（製造業採購經理人指數）

- **台灣 PMI 來源**：中華經濟研究院每月發布
- **判讀**：
  - **PMI > 50**：製造業擴張
  - **PMI < 50**：製造業收縮
  - **新訂單 PMI** 是領先指標
- **歷史對照**：
  - PMI 連續 3 個月 < 50 → 台股年線修正機率高
  - PMI 由 50 以下重返 50 以上 → 製造業回溫訊號

### 2.4 M1B 與 M2 貨幣供給

- **意義**：M1B（活期存款 + 支票存款）相對 M2 的增速，稱為「**M1B 年增率**」
- **股市資金面訊號**：
  - **M1B 年增率 > M2 年增率 → 資金動能強**
  - 歷史經驗：M1B 突破 10% 以上，常見股市資金動能充足
- **死亡交叉（M1B 下穿越 M2）**：歷史經驗視為**資金動能轉弱**訊號

```
台股資金動能領先指標（領先約 3–6 個月）：
M1B 上升 + M1B > M2 → 偏多
M1B 下降 + M1B < M2 → 偏空
```

### 2.5 其他總經指標

| 指標 | 對台股的影響 |
|------|--------------|
| **美元指數（DXY）** | 強勢美元 → 新興市場資金流出，弱勢美元利多 |
| **美國 10 年期公債殖利率** | 殖利率走升 → 全球資金回流美債，台股壓力 |
| **費城半導體指數（SOX）** | 與台股半導體類股高度相關 |
| **南韓 KOSPI / 日經** | 同為亞洲科技出口國，連動高 |
| **VIX（恐慌指數）** | 高於 25 → 全球避險情緒升溫 |
| **油價** | 影響塑化、航運成本與通膨 |

## 三、產業分析框架

### 3.1 電子業（佔台股市值近 70%）

#### 半導體

- **生態鏈**：
  - **上游**：IC 設計（如聯發科 2454、瑞昱 2379）
  - **中游**：晶圓代工（**台積電 2330**、聯電 2303）、記憶體（華邦電 2344、南亞科 2408）
  - **下游**：封測（日月光 2311、力成 6239、京元電子 2449）
  - **周邊**：矽智財（IP）、EDA 工具、設備廠
- **指標訊號**：
  - 費城半導體指數（SOX）方向
  - 台積電法說會展望
  - **摩爾定律**與製程推進節奏（3nm、2nm 推進時程）

#### 面板

- **代表**：友達（2409）、群創（3481）
- **特性**：週期性強、產能擴張快速 → 容易陷入價格戰
- **指標**：面板報價（每月公布）

#### PCB（印刷電路板）

- **代表**：欣興（3037）、南亞電路板（8046）、華通（2313）
- **與半導體關係**：受惠於載板（ABF、BT）與 HDI 需求

#### 散熱模組

- **代表**：奇鋐（3017）、雙鴻（3324）、超眾（6230）
- **成長動能**：AI 伺服器、高階 GPU 散熱需求

#### AI 供應鏈

- **上中下游分工**：
  - **AI 晶片**：台積電（代工）、聯發科（邊緣 AI）
  - **AI 伺服器組裝**：鴻海（2317）、廣達（2382）、緯創（3231）、英業達（2356）
  - **散熱與電源**：奇鋐、台達電（2308）
  - **記憶體與 HBM**：南亞科、華邦電
  - **PCB 與載板**：欣興
- **指標訊號**：北美四大雲端服務商（CSP）資本支出展望、GPU 發表週期

### 3.2 金融保險業

- **代表**：
  - **金控**：富邦金（2881）、國泰金（2882）、中信金（2891）、兆豐金（2886）
  - **壽險**：國泰人壽、富邦人壽
  - **銀行**：兆豐銀行、玉山金（2884）
- **基本面分析重點**：
  - **淨利差（NIM）**：升息利多
  - **淨值比**：股價淨值比（P/B）判斷便宜度
  - **保單負債**：壽險公司久期搭配外匯避險
  - **股息殖利率**：金融股是台股高殖利率重要來源

### 3.3 傳統產業

#### 塑化

- **代表**：台塑（1301）、南亞（1303）、台塑化（6505）
- **與油價連動性高**
- **指標**：西德州原油（WTI）、布蘭特原油

#### 鋼鐵

- **代表**：中鋼（2002）、大成鋼（2027）
- **與中國基建、房市連動**：中國 PMI 為重要外溢訊號

#### 紡織

- **代表**：聚陽（1477）、儒鴻（1476）
- **特性**：成衣代工出口產業，受全球景氣影響

#### 航運

- **代表**：長榮（2603）、陽明（2609）、萬海（2615）
- **特性**：
  - 高度景氣循環
  - **運價指數**（SCFI、BDI）為領先訊號
  - 大幅波動 → 飆股與急跌並存

### 3.4 生技醫療

- **代表**：
  - **學名藥**：晟德（4123）、中化（1701）
  - **新藥 / 生技**：東洋（4105）、藥華藥（6446）、合一（4743）
  - **CDMO**：保瑞（6472）、台康生技（6589）
- **特性**：
  - **事件驅動**：臨床試驗解盲、藥證核准利多
  - **估值高**：常用 P/S、pipeline / EV 對比
  - **波動大**：資本額小、籌碼集中個股多

### 3.5 產業輪動觀察

```
復甦初期：金融 → 工業 → 消費
擴張中期：科技 → 設備 → 出口
擴張末期：能源 → 公用事業
衰退期：防禦性類股（食品、電信、醫療）
```

## 四、個股分析

### 4.1 三大基本指標：EPS、PE、PB

#### 每股盈餘（EPS, Earnings Per Share）

```
EPS = 歸屬於母公司淨利 ÷ 加權平均流通在外股數
```

- **重要性**：決定公司是否真的有賺錢
- **連續性**：連續 3 年 EPS 正成長是基本品質指標

#### 本益比（PE）

```
PE = 股價 ÷ EPS
```

- **台股常見區間**（視產業別）：
  - **金控 / 銀行**：8–12 倍
  - **塑化 / 鋼鐵**：10–15 倍
  - **半導體 / 科技龍頭**：15–25 倍
  - **生技（獲利穩定）**：20–35 倍
  - **新藥 / 高成長科技**：40 倍以上甚至本夢比
- **修正用法**：用「**未來 12 個月預估 EPS**」算 Forward PE，比 Trailing PE 更具參考性

#### 本淨比（PB）

```
PB = 股價 ÷ 每股淨值
```

- **用途**：
  - 金融股最常使用（< 1 表「帳面價值打折」）
  - 重資產產業（航運、鋼鐵、塑化）的便宜度判斷
- **台股參考區間**：依產業差異極大（科技 5–10，金融 0.8–1.5）

### 4.2 股息殖利率

```
現金股息殖利率 = 每股現金股息 ÷ 股價
```

#### 台股高殖利率特性

- **台股平均殖利率**：3%–4%（高於多數成熟市場）
- **高股息 ETF 家族**：對市場意義重大
  - **0056、00878、00929、00919** 等 ETF 將台股「高股息」性質商品化
- **殖利率 > 5%** 的個股：進入「高殖利率關注區」，但需留意股利穩定性

#### 股利政策觀察

- **連續配發**：連續 10 年以上發放股息 → 重視股東報酬
- **配發率**：現金股利 ÷ EPS，介於 50%–80% 屬常見
- **保留盈餘比率**：成長股可低於 30%（保留擴張資金）

### 4.3 ROE 與 ROA（經營效率）

```
ROE = 稅後淨利 ÷ 股東權益（衡量股東報酬率）
ROA = 稅後淨利 ÷ 總資產（衡量資產運用效率）
```

- **優等公司**：
  - ROE 連續 5 年 > 15% → 質優
  - ROE 連續 5 年 > 20% → 卓越
- **ROE 杜邦分析**（三因子）：
  - ROE = 淨利率 × 資產周轉率 × 權益乘數
  - 找高 ROE 來源：
    - 高淨利率（品牌、護城河）vs 高周轉率（量販）vs 高槓桿（金融）

### 4.4 月營收年增率（YoY）

#### 這是台股最重要的短期基本面訊號

```
每月 10 日前公布 → 市場觀察重點
```

- **強勢訊號**：連續 3 個月 YoY > 20%
- **轉弱訊號**：YoY 增速連續 2 個月下滑（如 20% → 12% → 5%）
- **基期效應**：低基期 + 復甦 = YoY 高，但需深度檢視

#### 月營收 vs 季報的時間軸

```
每月 10 日前 → 上月營收
每季 45 天內 → 上季 EPS
```

### 4.5 綜合評分（LLM 引用建議）

```
基本面強度評分：
營收 YoY + EPS 雙成長      → 5 分
股息殖利率 > 4%            → 4 分
ROE > 15%                  → 5 分
低 PE / 低 PB（產業比較）    → 3 分
債務比 < 60%              → 4 分
```

## 五、台股特有的基本面特徵

### 5.1 淺碟市場特性（Thin Market）

- [[concepts/taiwan-stock-market-structure|權值股與市場結構]]：少數權值股佔大盤 60% 以上
- **中小型股**：易出現流動性風險
- **波動大**：個股單日跌幅可達 10%、20%
- **政策敏感**：政府護盤、國安基金動作對市場有即時影響

### 5.2 權值股主導（指數 = 少數個股）

#### 加權指數前十大權值股（2024 年起）

| 排名 | 代號 | 名稱 | 權重約 |
|------|------|------|--------|
| 1 | 2330 | 台積電 | **30%+** |
| 2 | 2317 | 鴻海 | 3–5% |
| 3 | 2454 | 聯發科 | 2–4% |
| 4 | 2881 | 富邦金 | 1–2% |
| 5 | 2882 | 國泰金 | 1–2% |
| 6 | 2308 | 台達電 | 1–2% |
| 7 | 2303 | 聯電 | 1–2% |
| 8 | 2891 | 中信金 | 1–2% |
| 9 | 2886 | 兆豐金 | 1–2% |
| 10 | 2327 | 國巨 | < 1% |

#### 重要衍生結論

- **台積電漲跌 = 大盤表現**：台積電當日 ±3% → 大盤通常同步 ±1% 以上
- **少數幾檔決定整體方向**：這與美股（權值分散）、陸股（國有大型股多元）差異極大
- **被動投資浪潮放大權重**：0050、006208 等 ETF 持續買超台積電 → 反饋效應

### 5.3 家族 / 集團企業比重高

- **台塑集團**（6 大公司）
- **鴻海集團**（鴻海、群創、台揚、建漢等）
- **聯發科集團**
- **統一集團**
- **富邦集團**
- **國泰集團**
- **中信集團**

集團個股常有同向連動特性（因集團資源、交叉持股、政府政策影響）。

### 5.4 散戶比重極高

- **自然人佔成交值**：常態 50%–60%
- 對應：
  - 籌碼面訊號重要（融資、當沖比例）
  - 訊息面驅動行情常見（新聞、論壇、社群）
  - 「**主力 / 作手**」文化仍存在，但隨 ETF 規模上升而稀釋

### 5.5 政策與法規環境影響大

- **半導體政策**：國家重點扶持產業
- **高股息 ETF**：主管機關鼓勵 → 推升高殖利率 ETF 規模
- **當沖稅率優惠**：影響當沖成交量

## 六、財報公布時程

### 6.1 年報（Annual Report）

- **公佈期限**：年度結束後 **3 個月內**（例如 12 月 31 日結束的年度 → 3 月 31 日前公布）
- **公布位置**：公開資訊觀測站（MOPS）與公司網站
- **內容**：
  - 合併財務報表（資產負債表、損益表、現金流量表、權益變動表）
  - 經營展望
  - 重大訊息揭露

### 6.2 季報（Quarterly Financial Report）

- **公佈期限**：每季結束後 **45 天內**（注意在 2024 年起，**Q2 為 60 天**）
  - Q1：5/15 前
  - Q2：8/14 前（或 8/15）
  - Q3：11/14 前
  - Q4：隔年 3/31 前（與年報合併揭露為主）
- **重點欄位**：營收、毛利率、營業利益率、稅後淨利、EPS、營業現金流

### 6.3 月營收（Monthly Revenue）

- **公佈期限**：**次月 10 日前**
- **重要等級**：台股最重要的「**短期基本面指標**」
- **公告欄位**：當月營收、累計營收、年增率（YoY）、月增率（MoM）
- **市場反應**：
  - 月營收 → 對股價的即時影響往往超過季報（因為公布頻率高）
  - 月營收連續 3 個月繳出好成績 → 市場會「**提前卡位季報**」

### 6.4 重大訊息（Material Information）

- **公佈時機**：發生重大事件時即時（依重大性分級 30 分鐘 / 24 小時 / 5 個營業日內）
- **內容**：合併、收購、減資、停工、董監變動、即時重大訊息等

### 6.5 公布時程速查表

| 報告類型 | 公布頻率 | 公布時限 | 重點用途 |
|----------|----------|----------|----------|
| 月營收 | 每月 | 次月 10 日前 | 短期動能追蹤 |
| 季報 | 每季 | 45–60 天內 | 中期獲利檢視 |
| 年報 | 每年 | 年度結束後 3 個月 | 全年結構檢視 |
| 重大訊息 | 不定期 | 30 分鐘 / 24 小時 / 5 日 | 事件驅動行情 |

## 七、實務決策架構（給 LLM 引用）

### 7.1 多頭結構檢核表

```
[ ] GDP 成長 > 2.5%
[ ] PMI > 50 連續 3 月
[ ] M1B 年增率 > M2 年增率
[ ] 主要利率維持或降息
[ ] 大盤站穩 MA60 月線
[ ] 權值股（台積電）多頭排列
[ ] 外資現貨連續買超
```

```
[ ] 連續 2 個月 PMI < 50
[ ] M1B < M2（死亡交叉）
[ ] 主要央行升息
[ ] 大盤跌破年線（MA240）
[ ] 外資連續 10 日以上賣超
[ ] 融資餘額急速下降（斷頭潮）
[ ] VIX > 30
```

## 八、小結

```
台股基本面 = 總經 + 產業 + 個股，三層交叉驗證
關鍵點：
1. 月營收是台股最即時的基本面指標
2. 半導體（尤其台積電）對大盤至關重要
3. 高殖利率是台股特色（金融 + 高股息 ETF）
4. 集團個股連動性高
5. GDP / PMI / M1B 為主要總經訊號
```
