# 台股技術分析手冊

> **一句話**：台股技術分析承襲道氏理論與傳統指標框架，但因除權息缺口、淺碟市場波動與[[concepts/taiwan-stock-market-structure|權值股]]主導等特性，需在參數設定與訊號解讀上做本土化調整。

## 一、技術分析三大假設

### 1.1 假設一：市場行為反映一切（Discount Everything）

- 所有[[concepts/taiwan-fundamental-analysis-guide|基本面]]、心理面、政策面的資訊，最終都已反映在「價格」與「成交量」上
- 因此，**研究 K 線 + 量即可推論市場對於事後事件的定價結果**
- 在台股特別成立：因為市場效率高且流動性集中，價格快速反應訊息

### 1.2 假設二：價格呈趨勢移動（Price Moves in Trends）

- 趨勢三種：上升、下降、盤整（橫向）
- 一旦趨勢成形，傾向**延續**而非立即反轉（慣性原理）
- 台股慣性特徵：
  - 多頭趨勢期間，月線常延續 6–12 個月
  - 空頭趨勢則常見急跌 + 長底型修正

### 1.3 假設三：歷史會重演（History Repeats）

- 人類對恐懼與貪婪的反應模式世代相傳
- 因此經典型態（頭肩頂、三角收斂、雙重底等）有反覆出現的特性

## 二、道氏理論核心

### 2.1 三種趨勢

| 趨勢層級 | 時間 | 描述 |
|----------|------|------|
| 主要趨勢（Primary） | 數月至 1–2 年 | 牛市 / 熊市 |
| 次級趨勢（Secondary） | 數週至數月 | 反彈 / 回檔 |
| 短期波動（Minor） | 數日 | 日內雜訊 |

### 2.2 三個理論核心

1. **價格反映一切**：所有已知 + 未知資訊已 in pricing
2. **三種趨勢同存**：分析必須區分層級
3. **主要趨勢分三階段**：
   - 累積期（Accumulation）：少數知情者進場
   - 公開期（Public Participation）：大眾參與
   - 分配期（Distribution）：聰明錢出場

### 2.3 應用提醒

- 道氏無法判斷「頂部何時到」，但能辨識多 / 空市場
- 在台股具體應用：判斷台股是否進入「長期多頭結構」有助於選擇股票 vs 期貨策略

## 三、趨勢線與型態學

### 3.1 趨勢線繪製原則

- **上升趨勢線**：連接「低點」與「低點」，位於 K 線下方，作為支撐
- **下降趨勢線**：連接「高點」與「高點」，位於 K 線上方，作為壓力
- **有效突破條件**：
  - 收盤價**突破**非僅觸及
  - 連續 2–3 天未跌回（過濾假突破）
  - 配合成交量放大

### 3.2 重要反轉型態

#### 頭肩頂（Head and Shoulders Top）— 反轉向下

```
       ╱╲         ╱╲
      ╱  ╲       ╱  ╲       ← 右肩
     ╱    ╲     ╱    ╲
            ╲  ╱
             ╲╱          ← 頭部（最高）
       
   1:左肩 ── 頸線 ── 2:右肩
            ↓
       跌破頸線 = 反轉確認
```

- 跌幅估算：頭部至頸線的垂直距離
- 台股案例：2021 年台積電在 600–700 區間形成大型頭肩頂

#### 頭肩底（Inverse H&S）— 反轉向上

- 結構與頭肩頂對稱，反向解讀
- 突破頸線後常為短中線起漲點

#### 雙重頂（M-Top / Double Top）

- 兩個相近高點的高點 + 中間低點跌破
- 確認訊號：中間高點跌幅的 1 倍延伸目標

#### 雙重底（W-Bottom / Double Bottom）

- 對稱反向，常稱「W底」或「鑽石底」
- 突破中間高點頸線即為買訊

### 3.3 整理型態（延續型態）

#### 三角形（Symmetrical Triangle）

```
        ╲       ╱
         ╲     ╱
          ╲   ╱
           ╲ ╱
            X
           ╱ ╲
          ╱   ╲
```

- 高點下降 + 低點上升 → 收斂 → 突破方向為主
- 三種變體：
  - 對稱三角形（最常見）
  - 上升三角形（多頭偏強）
  - 下降三角形（空頭偏強）

#### 旗形（Flag / Pennant）

- 急漲 / 急跌後的小型反向整理
- 與原趨勢同向突破：原趨勢的延續訊號
- 常見：台股多頭起漲初升段 + 旗形整理 = 再漲段啟動

#### 矩形（Rectangle）

- 高低點區間水平整理
- 在台股常見於「牛皮盤」階段

## 四、K 線基本型態

### 4.1 單日 K 線

| 型態 | 型狀 | 解讀 |
|------|------|------|
| **大陽紅** | 實體大、幾乎無上下影線 | 多方強勢 |
| **長下影線** | 下影 ≥ 實體 2 倍 | 下方有承接 |
| **長上影線** | 上影 ≥ 實體 2 倍 | 上方賣壓重 |
| **十字星** | 開收幾乎同價 | 多空均衡、轉折訊號 |
| **墓碑線** | 上影極長，無下影 | 高檔反轉警訊 |
| **鎚子 / 吊人** | 下影極長，實體小 | 低檔反轉警訊 |

### 4.2 兩日 / 三日 K 線組合

- **吞噬（Engulfing）**：後一日 K 線實體完全包覆前一日
  - 多頭吞噬：低檔反轉
  - 空頭吞噬：高檔反轉
- **母子線（Harami）**：後一日實體在前一日實體內（懷孕）
- **晨星（Morning Star）/ 昏星（Evening Star）**：三根組合，低 / 高檔反轉

### 4.3 台股特有的 K 線注意點

- **除權息日會留下大缺口**：實務上以「還原權值」K 線解讀較有意義
- **特殊產業（航運、DRAM）出現連續一字線**：訊息面強勢鎖單
- **當沖成分高的個股**：盤中波動幅度大，但收盤往往縮小 K 線實體（注意「假突破」風險）

## 五、常用技術指標與台股參數設定

### 5.1 移動平均線（Moving Average, MA）

| 週期 | 用法 | 台股慣用 |
|------|------|----------|
| **MA5** | 短期趨勢 | 日線短期支撐 |
| **MA20** | 月線，可視為短期生命線 | 中短期強弱分界 |
| **MA60** | 季線 | 多空重要分水嶺 |
| **MA120** | 半年線 | 中期趨勢方向 |
| **MA240** | 年線 | 長期多空分界 |

#### 台股口訣

```
股價站上 MA60 月線才稱多頭
MA60 上揚 → 中期多頭結構
MA60 走平下彎 → 警戒
股價跌破 MA120 = 強勢股轉弱
```

#### EMA vs SMA 在台股偏好

- **SMA（簡單移動平均）**：傳統派採用，對所有資料點等權重
- **EMA（指數移動平均）**：近期權重較高，反應快
- 台股實務：短線常用 EMA20，長線仍看 SMA

### 5.2 MACD（Moving Average Convergence Divergence）

#### 參數

- 預設 12 / 26 / 9（快線、慢線、訊號線）
- 柱狀圖（Histogram）= MACD − Signal

#### 應用

- **黃金交叉**：MACD 向上穿越 Signal → 多頭進場
- **死亡交叉**：MACD 向下穿越 Signal → 多頭出場
- **柱狀圖背離**：
  - **多頭背離**：股價新低、MACD 柱狀圖未新低 → 反轉向上
  - **空頭背離**：股價新高、MACD 柱狀圖未新高 → 反轉向下

#### 台股背離特殊應用

- 權值股（台積電、鴻海、聯發科）的 MACD 背離對大盤有**領先訊號**
- 月線 MACD 死亡交叉常常是多頭趨勢結束的先兆

### 5.3 RSI（Relative Strength Index）

#### 傳統參數與台股調整

| 項目 | 傳統 | **台股實務** |
|------|------|---------------|
| 區間長度 | 14 | 14 |
| 超買區 | 70 | **80** |
| 超賣區 | 30 | **20** |

**為何台股慣用 80/20？**
- 台股波動性高，過去常用 70/30 容易觸及超買超賣區域，導致假訊號多
- 80/20 較能過濾盤中波動噪音

#### RSI 鈍化

- 強勢多頭：RSI 持續 > 80 不回 → 不預設為賣點
- 「**RSI 鈍化**反而是趨勢強勢」是台股常見誤解關鍵

#### 應用

- RSI < 20 但 K 線出現長下影 + 量縮 → 底部可能形成
- RSI 在 50 附近徘徊 → 盤整
- 突破 RSI 50 → 中短線多空分水嶺

### 5.4 KD 指標（Stochastic Oscillator）

#### 參數

- 預設 9/3/3（即 %K=9, %K 平滑 3, %D 平滑 3）

#### 解讀

- **K > 80**：超買區
- **K < 20**：超賣區
- **黃金交叉**：K 向上穿越 D
- **死亡交叉**：K 向下穿越 D

#### 台股應用

- **震盪盤時好用**：KD 在區間行情的反轉判定較靈敏
- **強勢多頭慎用**：會持續在 80 以上鈍化（如同 RSI）
- 日 KD 與週 KD 背離 = 中期反轉訊號

### 5.5 布林通道（Bollinger Bands）

#### 參數

- 預設 20 日均線 ± 2 標準差

#### 應用

- 股價觸上軌 + 成交量未明顯放大 = 可能過熱
- 股價觸下軌 + 出現長下影 = 可能止跌
- **軌道收窄 → 喇叭口張開**：常見大波動前兆
- **軌道持續擴張超過 3 個月**：趨勢進入末段訊號

#### 台股權值股有效性

- 對台積電、鴻海、台達電、聯發科等**高流動性權值股**，布林通道訊號相對可靠
- 對**低成交量小型股**或當沖過熱標的，效果差（因為雜訊太多）

### 5.6 其他常用指標

| 指標 | 用途 | 注意 |
|------|------|------|
| **OBV** | 量能確認趨勢 | 與股價背離時視為反轉警訊 |
| **SAR** | 趨勢追蹤 / 停損點 | 在震盪盤容易發出假訊號 |
| **DMI / ADX** | 判斷趨勢強度 | ADX > 25 為趨勢確立 |
| **ATR** | 衡量波動度 | 用於設定停損距離 |

## 六、成交量分析

### 6.1 價量關係核心

- **量先價行**：底部常見「量縮 → 量增」伴隨股價起漲
- **價漲量增**：健康多頭
- **價漲量縮**：背離，可能虛漲
- **價跌量增**：恐慌賣壓，常見底部大量
- **價跌量縮**：弱勢整理，方向尚未明
- **價平量增**：方向即將出現

### 6.2 台股成交量特性

- **集中市場日均量**：2020 年代中期常態約 2,500–4,500 億
- **櫃買市場日均量**：約 600–1,200 億
- **OTC 流動性集中**：股本小但成交比高的小型股，常見周轉率 20% 以上
- **當沖成交量占比**：2024 年集中市場當沖買賣佔比可達 40–55%（部分個股）

### 6.3 量能黃金訊號

- **底部起漲**：突破均量（如月均量）時量增 1.5–2 倍
- **攻擊量**：連續 3 日大量 + 長紅 K
- **末升段**：動輒爆出歷史天量，搭配「量增價不漲」警訊
- **退潮訊號**：爆量後收長上影，隔日量縮下跌 → 反轉

## 七、台股技術分析的特殊性

### 7.1 除權息的股價缺口

```
除息前 100 元 ÷ 配息 2 元 = 除息後參考價 98 元
除權前 100 元 ÷ (1 + 配股 0.5) = 除權後參考價 66.67 元
```

- **「右側缺口」**：除權息當日的 K 線會留下大跳空，**這並非真實的跌勢**
- 但對「未還原」的股價圖表而言，看起來會像大跌
- 影響：指數（如加權指數）會因除權息而產生非交易性變動

### 7.2 還原權值的方式

| 類型 | 還原方式 | 用途 |
|------|----------|------|
| **前復權** | 將除權息「向前調整」，讓過去 K 線也同步下降 | **看長期趨勢**（常用） |
| **後復權** | 將除權息「向後調整」，保留近期 K 線原貌 | 計算「含息報酬」的長線走勢 |

**LLM 引用技術分析結論時，建議優先指定「前復權」K 線，除非是做歷史含息報酬分析。**

### 7.3 高股息 ETF 的「配息後」缺口

- 0056、00878 等 **月配 / 季配 ETF** 在配息日也會留缺口
- 觀察時應以「還原息值後」的 K 線判斷真實走勢

### 7.4 當沖對技術面的影響

- **盤中訊號失真**：高當沖占比個股的盤中「假突破」多
- **收盤價意義放大**：建議以**收盤價 + 收盤量**為主
- **留意尾盤異常大量**：常為當沖了結，非真實方向訊號

### 7.5 權值股對指數的失真放大

- 加權指數中台積電權重可達 30% 以上（與世界先進等小股相比極度傾斜）
- 因此權值股的技術面訊號與大盤幾乎重合
- 反之，**櫃買指數（OTC）**相對更能反映中小型股的技術面結構

## 九、組合判讀最佳實務

### 9.1 多重確認原則

LLM 引用技術分析結論時，應**結合至少 2 種以上訊號**才能形成較具體的判讀：

```
範例（多頭訊號）：
- 日線站上月線（MA20 上 MA60）
- MACD 柱狀圖由負轉正
- 成交量 > 月均量 1.5 倍
- KD 黃金交叉且 K 值大於 50
- 出現底部型態（如雙重底）
```

### 9.2 留意的失效情境

- **極端事件**：央行降息、戰爭、系統性風險 → 技術訊號全失真
- **低流動性個股**：技術指標反覆閃爍
- **當沖過熱**：盤中訊號雜訊大，尾盤才有結論
- **除權息**：需先確認是否使用還原權值 K 線

## 十、小結

```
台股技術分析 = 全球指標 + 台灣本土調整
關鍵點：
1. RSI 用 80/20 而非 70/30
2. 月線（MA20）才是生命線，而非 MA10
3. 還原權值 K 線為預設基準
4. 量能搭配比單純指標更具參考性
5. 權值股技術面影響指數，OTC 反映中小型股
```
