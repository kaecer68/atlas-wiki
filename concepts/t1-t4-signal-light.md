# T1→T4 訊號燈四層驅動結構

> **一句話定義**:**T1 美股 = 信號燈**(全球方向),**T2 外資 = 引信**(美股→台股傳遞執行者),**T3 其他法人 = 真正指標**(對殺方向),**T4 散戶 = 鏡像 / 韭菜**(落後反應者)。**這四層的真實驅動順序是 T0 → T1 → T2 → T3 → T4**(從真實事件到表象反應)。

這是 v0.4 訊號燈的**核心四層結構**,**也是 kaecer 2026-07-15 拍板**的「真實驅動」邏輯。

---

## 為什麼是「**四層**」而非「**三層**」或「**五層**」?

我之前 v0.2 / v0.4 寫過不同版本:
- v0.2 寫成「**Level 1/2/3 三層**」:錯,因為「**散戶 = 鏡子**」是重要第四層
- v0.3 寫成「**T1→T4 四層**」+ 6 個異常案例:這個是對的

**kaecer 2026-07-15 拍板**:**美股是信號燈,外資走向是引信,其他法人對殺的策略是真正的指標,散戶情緒都是被帶風向的鏡子或韭菜**。

這個拍板的**精妙之處**:**四層不是平等的**:
- T1(美股)是「**真相的源頭**」
- T2(外資)是「**真相傳遞到台股的執行者**」
- T3(其他法人)是「**真相在台股內部怎麼被消化的對殺**」
- T4(散戶)是「**真相的鏡像(但已經晚了)**」

---

## 四層的真實關係

```
┌─────────────────────────────────────────┐
│ T0 真實驅動:L1 引爆 → 全球事件發生       │ ← 鐵律的 L1(美伊戰爭 / Fed / 戰爭)
└─────────────────────┬───────────────────┘
                      ↓
┌─────────────────────────────────────────┐
│ T1 信號燈:美股方向(道瓊/S&P/那指/VIX)  │ ← 當晚美股怎樣,隔日台股就怎樣(主層)
└─────────────────────┬───────────────────┘
                      ↓
┌─────────────────────────────────────────┐
│ T2 引信:外資走向(美股→台股傳遞執行者)  │ ← 佔台股 4 成成交,跟隨美股 ADR 連動
└─────────────────────┬───────────────────┘
                      ↓
┌─────────────────────────────────────────┐
│ T3 內部鬥爭:其他法人(投信/自營/官股)   │ ← 真正指標
│     對殺策略                              │ ← 對「方向 + 籌碼 + 成本」最敏感
└─────────────────────┬───────────────────┘
                      ↓
┌─────────────────────────────────────────┐
│ T4 表象鏡像:散戶情緒 → 鏡子 / 韭菜      │ ← 最後的反應者 / 被收割對象
└─────────────────────────────────────────┘
```

## 四層各自的「**實戰應用**」

### T1 美股信號燈 — 每日 08:00 必看

**核心訊號**:
- **S&P 500 / 那斯達克 / 道瓊 / VIX**(總體)
- **費半 SOX**(台股關鍵)
- **台積電 ADR TSM**(台股隔日最直接)
- **NVDA / AMD**(AI 供應鏈情緒)

**實戰應用**:**08:00 看 T1 收盤,確認當日大方向**

**kaecer 拍板「**找漏洞**」邏輯**:**會用 AI 的散戶比不會用 AI 的散戶快 5 分鐘解讀事件**。這 5 分鐘的「**解讀時間差**」= T1 階段的 alpha。

### T2 外資引信 — 09:00 開盤前最敏感

**核心訊號**:
- **TWSE 5 分鐘揭露三大法人**(台灣核心)
- **摩台指收盤**(亞洲盤前情緒)
- **台指期夜盤**(散戶可對沖)
- **台積電 ADR 與 2330 價差**(套利機會)

**實戰應用**:**09:00 看 T2 即時,確認「**信號燈是否被引燃**」**

**為什麼 T2 是「**引信**」**:**美股方向的「**執行**」,要靠外資把美元流動性傳遞到台股。**沒有 T2 引信,T1 信號燈是「**亮著但沒人執行**」**。

### T3 其他法人對殺 — 09:00-13:30 持續觀察

**核心訊號**:
- **投信買賣超**(T+1,但方向穩定)
- **自營商避險倉 vs 造市倉**(T+1)
- **官股進出場**(護盤訊號)
- **融資券變化**(即時)
- **三大法人合計**

**實戰應用**:**持續監測 T3,確認「**內部對殺誰勝出**」**

**為什麼 T3 是「**真正指標**」**:**T3 的投信 / 自營 / 官股**對「**方向 + 籌碼 + 成本**」的判斷最敏感**。他們的動作反映**真正的「**共識**」**。**但這個共識是「**不透明**」**的,要靠訊號觀察。

### T4 散戶鏡像 — 持續觀察但不是「指標」

**核心訊號**:
- **0050 / 006208 / 00878 申購贖回**(T+1)
- **0050 即時折溢價**(即時,**v0.4 新增**)
- **PTT / Dcard 熱度**(DeepSeek + Kimi 兩份 audit 都建議刪除或取代)

**實戰應用**:**T4 是鏡像,不是指標。T4 在「趨勢末段」才是「**確認訊號**」**

**為什麼 T4 是「**鏡子 / 韭菜**」**:**散戶是最慢反應者。**T1/T2/T3 都已動完,散戶才看到新聞**。但 T4 有「**確認趨勢末段**」的功能:**散戶大量湧入 = 趨勢末段**。

## 四層的「**收斂**」(從 S 到 L/T 的關鍵)

**收斂定義**:**T1/T2/T3 三層同向 + T4 一致** = 訊號燈收斂
- T1 美股方向明確(綠或紅)
- T2 外資走向同步(同向)
- T3 法人對殺收斂(同向)
- T4 散戶反應一致(冷或熱)

**收斂時**:**atlas-go 可以判定「**這是 L 後段或 T 範式**」** — S 狀態結束。

**未收斂時**:**atlas-go 應判定「**這是 S 範式**」** — **不進場,持續監測**。

## 為什麼 v0.4 的 I1/I3 是「**過度強調**」?

v0.4 提到:
- **I1**:**延遲性**是 alpha(機構延遲 / 散戶即時)
- **I3**:**資料延遲**是 alpha(5 分鐘揭露)

**DeepSeek + Kimi 兩份 audit 都警告**:
- 實務上 I1 的 alpha 幅度 < 0.3%,扣成本後趨近於 0
- I3 的 5 分鐘後動量 0.1-0.3%,**方向性確認** ≠ **可獲利**

**所以 v0.4 的 I1/I3 應該重新標記**:
- I1/I3 = **「方向性確認訊號」**,**不是「可獲利訊號」**
- 真實 alpha 在 T1/T2/T3 **收斂時**的「S 解除」那一刻,不是「**個別訊號**」
